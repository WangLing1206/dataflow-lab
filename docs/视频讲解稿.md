## 镜头 2｜核心亮点：图形化的「寻找最值」（0:14 – 0:32）

**操作**：点「去除极值」→ 参数（极值 / 语文 / 两端各 1 个）→ 「运行全部」。

**画面重点**：
1. 表格探针逐格扫描，HUD 实时显示 `扫描进度 / 当前最小 / 当前最大 / 当前值`；
2. **右侧图表同步画出轨迹**：红线是「当前最大」的上升阶梯线，蓝线是「当前最小」的下降阶梯线，
   圆点是当前扫描到的值，图内标注「当前最小 58 / 当前最大 100」与「扫描进度 16/24」；
3. 扫描结束，标记停在真正的极值行上（韩星洲 100 标红、傅明澈 57 标蓝）；
4. 极值行淡出、收起，其余行上移，**图表里的柱子也跟着掉落**；
5. 结论：删除 2 行，剩余 22 行，新区间 58 ~ 95。

**字幕**：`去除极值：表格探查针扫描，图表同时画出「当前最小/最大」的轨迹`
`蓝线是「当前最小」的下降轨迹，红线是「当前最大」的上升轨迹 —— 最值是这样被找到的`
`扫描结束 → 极值行被标记、逐行删除，图表里的柱子也跟着掉落`

**讲解词**：
> 先看最核心的一个操作：去掉一个最高分、一个最低分。
> 点击运行后，表格会逐格扫描，同时**右侧图表把它画成两条轨迹**：蓝线是"当前最小"一路下降，红线是"当前最大"一路上升。
> 这就是最关键的地方 —— 最大值不是凭空出现的，而是**被一步步比较出来的**，而这个过程是"看得见"的。
> 扫描结束，两个标记停在真正的极值上，然后这两行被逐行删除，图表里的分布也跟着重新长出来。
> 最后给出结论：删除 2 行，剩余 22 行，区间从 57~100 收敛到 58~95。

## 镜头 3｜清洗：缺失值 + 重复行（0:32 – 0:55）

**操作**：加入「缺失值处理」（填充 / 均值 / 数学）→ ▶；加入「去除重复」（姓名）→ ▶。

**画面重点**：缺失单元格逐格标红 → 数值滚动填进空位；重复行标黄后被删除；
扫描期间图表显示「保留 / 剔除」计数的实时增长。

**字幕**：`缺失值与重复行：逐格标红定位 → 均值滚入填充 / 重复指纹标黄删除`

**讲解词**：
> 接着做清洗。缺失值处理会先把空值一个个标红定位，再算出均值让数字滚动着填进去；
> 去除重复则给每一行算一个"指纹"，指纹重复的行标黄删除。
> 这两个步骤同样是先"找"再"改"，左边扫描的同时，右侧图表也在实时记录保留和剔除的数量。

## 镜头 6｜用图形做分析：质量与关系（1:37 – 2:03）

**操作**：回到原始数据 → 依次切换 缺失值热力图 / 数据画像 → 切到鸢尾花 → 散点矩阵。

**字幕**：`用图形做数据分析：缺失值热力图 / 数据画像 / 散点矩阵 / 处理前后对比`
`缺失值热力图：一眼看出缺失集中在哪一列、是否成片`
`数据画像：每列的类型、缺失率、基数与分布迷你图`
`散点矩阵：下三角是相关系数，一眼找到强相关的变量对`

**讲解词**：
> 图表不只是最后画一张图。这里有 14 种图表，分成基础、分布、关系、质量四组。
> 比如"缺失值热力图"，一眼就能看出缺失集中在哪一列、是不是成片出现；
> "数据画像"把每一列的类型、缺失率、取值数量和分布迷你图排在一起，就是一份数据体检报告；
> 换到鸢尾花数据，"散点矩阵"用下三角给出相关系数 —— 花瓣长和花瓣宽是 0.96，一眼就找到强相关的变量对。
> 还有一个"处理前后对比"，专门回答"这一步到底改变了什么"。

**讲解词**：
> 最后说下实现：整个网站是原生 HTML、CSS、JavaScript，**零第三方依赖、零构建**。

## 录制说明

成片已经**带语音讲解**：`docs/video/DataFlow-Lab-demo.mp4`
（3 分 47 秒，H.264 + AAC，1280×760；中文女声讲解，切到英文界面时自动换成英文女声）。

全流程三步、全部脚本化，可一键重做：

```bash
# 1) 起本地服务
python -m http.server 8123

# 2) 生成解说音轨（Windows 内置语音，离线合成；输出 narration.wav + 每段时长）
node tools/tts-narrate.mjs

# 3) 按解说时间轴自动录屏（画面动作会对齐到"说到哪、演到哪"）
node tools/record-demo.mjs --url http://127.0.0.1:8123/index.html --out docs/video

# 4) 音画合成 → MP4
node tools/mux-video.mjs
```

**工作原理**：

| 文件 | 作用 |
|---|---|
| `tools/narration.json` | 16 段解说词（中文 15 段 + 英文 1 段），可自行改写 |
| `tools/tts-sapi.ps1` + `tools/tts-narrate.mjs` | 调用 Windows 内置 TTS（Microsoft Huihui / Zira）逐段合成，拼接为完整音轨并记录每段起止时间 |
| `tools/record-demo.mjs` | 读取每段起止时间，**按绝对时间轴调度画面动作**，并记录音画对齐偏移 `lead` |
| `tools/mux-video.mjs` | 用 ffmpeg 以 `-itsoffset lead` 合成 MP4，保证语音与画面同步 |

> 想要换成自己的讲解，只需修改 `tools/narration.json` 里的文本，然后重跑第 2~4 步即可；
> 视频里同时有烧入字幕与网站自带解说条，**静音观看也能看懂**。
