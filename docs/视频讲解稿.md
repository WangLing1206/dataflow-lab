# DataFlow Lab 演示视频 · 分镜与讲解稿

> 时长目标 **约 3 分钟**（上限 5 分钟），共 9 个镜头。
> 视频中的「字幕」= 网站内置的顶部解说条 + 录制脚本烧入的说明字幕，可直接对照讲解。
> 录制脚本：`tools/record-demo.mjs`（Playwright 自动录屏，含虚拟光标与字幕，可一键重录）。

---

## 镜头 1｜开场：这个网站解决什么问题（0:00 – 0:18）

**画面**：页面全貌，默认载入的「学生成绩」数据集（30 行 × 8 列）。

**字幕**：`pandas 一行代码就出结果，但我们看不到中间发生了什么`

**讲解词**：
> 大家好，这是我的数据可视化作业 —— DataFlow Lab，一个可视化数据分析实验室。
> 用 pandas 处理数据时，`dropna`、`groupby` 一行代码就出结果，可数据到底经历了什么，我们看不见。
> 所以这个网站的目标只有一句话：**把 pandas 的每一步处理都「演」出来**。
> 界面分三块：左边是数据源和操作库，中间是分析流水线和动画舞台，右边是实时同步的结果面板。
> 左上角可以切换四个内置数据集，也可以导入自己的文件，默认打开的是学生成绩数据。

## 镜头 2｜核心亮点：去除极值，看见「寻找最值」的过程（0:18 – 1:05）

**操作**：点击操作库「去除极值」→ 参数面板出现（方式 = extreme，列 = 语文，两端各去掉 1 个）→ 点击「运行全部」。

**画面重点**：
1. 表格下方扫描探针逐格前进，右上角 **HUD 探针**实时刷新「扫描进度 / 当前最小 / 当前最大 / 当前值」；
2. 蓝色标记和红色标记在扫描中**不断移动**——"当前最小"从 79 变成 66，再变成 58；
3. 扫描结束，标记停在真正的极值上，解说报出「最小 58，最大 100」；
4. 两行极值被标记 → 依次淡出、右移、收起，其余行自然上移；
5. 结论条：删除 2 行，剩余 29 行，新区间 63 ~ 98。

**字幕**：`不是直接给结果，而是演示"最大值是怎么被找到的"`

**讲解词**：
> 先看最核心的一个操作：去除极值，也就是评委打分里常见的"去掉一个最高分、一个最低分"。
> 点击运行之后，它不会直接告诉你结果，而是先扫全列：右上角的探针面板实时显示扫描进度、当前最小值和当前最大值。
> 注意看标记——当扫到更小的值，蓝色标记**移动**到新的位置；扫到更大的值，红色标记移动。
> 扫描结束，两个标记停在真正的极值上；然后这两行被标记为待删除目标，依次淡出、收起，其他行自然上移。
> 最后给出结论：删除 2 行，剩余 29 行，数值区间从 58 到 100 收敛成了 63 到 98。
> 同一个操作还支持 IQR 异常值剔除和分位裁剪，逻辑同样会一步步演出来。

## 镜头 3｜继续做数据清洗：缺失值 + 重复行（1:05 – 1:30）

**操作**：加入「缺失值处理」（fillna / 均值 / 数学）→ 点 ▶ 单步播放；
加入「去除重复」（依据列：姓名）→ 点 ▶ 单步播放。

**画面重点**：缺失单元格被逐格标红（`⌀` 空值）→ 解说给出均值 → 数值**滚动**填进空位；
重复行扫描时右侧显示"保留 / 重复"计数，重复的「王思远」标黄并被删除。

**字幕**：`缺失值：先标红定位，再用均值滚入填充`

**讲解词**：
> 接着做清洗。加入「缺失值处理」，点播放键单步执行：它会先扫描作用列，把空值一个个标红定位，
> 然后计算出均值，让数值滚动着填进这些空位，你能清楚看到哪一格被填了什么。
> 再去做重：它给每一行算一个"指纹"，指纹重复的行会被标黄，最后把重复的「王思远」删掉。

## 镜头 4｜派生指标与排序：FLIP 平滑重排（1:30 – 1:50）

**操作**：加入「新增计算列」（总分 = 语文 + 数学 + 英语）→ ▶；
加入「排序」（总分降序）→ ▶。

**画面重点**：新列从右侧滑入，30 行数字逐个滚动生成；排序时先读取排序键，再整表平滑滑动重排。

**字幕**：`新增列从右侧滑入 · 排序是整表平滑重排，不是瞬间闪现`

**讲解词**：
> 接下来造一个派生指标：总分 = 语文 + 数学 + 英语。新列会从表格右侧滑入，然后逐行把结果算出来。
> 再按总分降序排序。这里用的是 FLIP 动画：先记录每一行的旧位置，移动之后再反向位移过渡回去，
> 所以看起来是整张表**平滑滑动**重排，而不是瞬间闪一下。

## 镜头 5｜分组聚合：上色 → 聚拢 → 坍缩（1:50 – 2:12）

**操作**：加入「分组聚合」，把「聚合列」改成 **总分**，函数 mean → ▶。

**画面重点**：同班行染同色 → 整表按组重排聚拢 → 每组被"吸"成一行，解说逐组报出「二班：7 行 → 均值 269.3」。

**字幕**：`分组上色 → 聚拢 → 坍缩成汇总行`

**讲解词**：
> 分组聚合是最容易被忽略过程的一步。这里先按班级给每一行上色，让同组的行聚到一起，
> 然后一组一组坍缩：组内多行飞到组首行的位置并消失，解说同步报出这一组的行数和均值。
> 四个班级最终变成四行汇总，右侧的描述统计和分布图也同步更新了。

**讲解词**：

> 速度支持 0.5 到 4 倍，4 倍速可以快速过一遍全流程；勾选"只看结果"就跳过动画直接落定。
> 右上角还能一键复制当前进度的等价 pandas 代码。

## 镜头 7｜换数据：比赛评分 + 自动演示（2:30 – 3:05）

**操作**：切换数据集为「比赛评分」→ 点击右上角「自动演示」。

**画面重点**：12 行 × 8 列、5 位评委打分的数据；自动播放完整流水线：填充缺失 → 去重 → 去极值 → 算均分 → 排序。

**字幕**：`换个数据集也一样：一键「自动演示」跑完整流程`

**讲解词**：
> 数据集可以随时替换。切到「比赛评分」——这是一份 5 位评委打分的数据，
> 点「自动演示」，它会自动跑完一整套流程：填充缺失的评分、去掉重复选手、剔除评委A的极值、
> 算出每位选手的平均分，最后排序。整个过程同样是一步一步演出来的。

## 镜头 9｜结尾：实现方式（3:20 – 3:40）

**画面**：回到学生成绩数据集，定格在整体界面（可再次播放一次极值扫描）。

**字幕**：`零依赖零构建 · 自研数据引擎 + 动画剧本架构`

**讲解词**：
> 最后说下实现：整个网站是原生 HTML、CSS、JavaScript，**零第三方依赖、零构建**。
> 数据处理跑的是我自己写的轻量 DataFrame 引擎，CSV 解析、类型推断、均值分位数、分组聚合都是自己实现的，
> 没有用任何 pandas 的 JS 移植库。
> 关键是动画架构：每个操作不返回"结果"，而是返回一条**动画剧本**——
> 扫描、比较、标记、删除、填充、聚合、落定，播放器只负责按剧本演出。
> 所以以后想加新操作，只要写一个 run 函数，动画和界面会自动支持。
> 谢谢观看。

## 录制说明

```bash
# 1) 起本地服务
python -m http.server 8123

# 2) 自动录屏（约 3~4 分钟，全程自动操作 + 虚拟光标 + 字幕）
node tools/record-demo.mjs --url http://127.0.0.1:8123/index.html --out docs/video

# 3) 生成的 webm/mp4 在 docs/video/ 下，可再配上本讲解词录音
```

> 说明：录屏脚本会自动操作网站（点击、调速、切数据集、粘贴数据），并**烧入说明字幕**，
> 网站自身的解说条也会同步显示，因此即使静音观看也能看懂；
> 若需要人声讲解，直接对照本稿逐镜头录制旁白即可（总时长 ≤ 5 分钟）。
