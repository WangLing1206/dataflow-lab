## 镜头 2｜核心亮点：去除极值，看见「寻找最值」的过程（0:12 – 0:32）

**操作**：点击操作库「去除极值」→ 参数面板出现（方式 = 极值 / 列 = 语文 / 两端各 1 个）→ 点击「运行全部」。

**画面重点**：
1. 表格下方扫描探针逐格前进，右上角 **HUD 探针**实时刷新「扫描进度 / 当前最小 / 当前最大 / 当前值」；
2. 蓝色标记和红色标记在扫描中**不断移动**——「当前最大」从 79 变成 94，再变成 100；
3. 扫描结束，标记停在真正的极值上，解说报出「最小 57，最大 100」；
4. 两行极值左侧亮起蓝 / 红色竖条 → 被标记为待删除目标；
5. 这些行依次淡出、右移、收起，其余行自然上移；
6. 结论条：删除 2 行，剩余 22 行，新区间 62 ~ 95。

**字幕**：`去除极值：先扫全列找最小最大值，再标记、逐行删除`
`扫描中：探针实时显示「当前最小 / 当前最大」，标记会随扫描移动`
`扫描结束 → 极值行被标记，随后逐行删除，其余行自然上移`

**讲解词**：
> 先看最核心的一个操作：去除极值，也就是评委打分里常见的"去掉一个最高分、一个最低分"。
> 点击运行之后，它不会直接告诉你结果，而是先扫全列：右上角的探针面板实时显示扫描进度、当前最小值和当前最大值。
> 注意看标记——当扫到更小的值，蓝色标记**移动**到新位置；扫到更大的值，红色标记移动。
> 扫描结束，两个标记停在真正的极值上；然后这两行被标记为待删除目标，依次淡出、收起，其他行自然上移。
> 最后给出结论：删除 2 行，剩余 22 行，数值区间从 57 到 100 收敛成了 62 到 95。
> 同一个操作还支持 IQR 异常值剔除和分位裁剪，逻辑同样会一步步演出来。

## 镜头 3｜数据清洗：缺失值 + 重复行（0:32 – 0:44）

**操作**：加入「缺失值处理」（填充 / 均值 / 数学）→ 点 ▶ 单步播放；
加入「去除重复」（依据列：姓名）→ 点 ▶ 单步播放。

**画面重点**：缺失单元格被逐格标红（`⌀`）→ 解说给出均值 → 数值**滚动**填进空位；
重复行扫描时右侧显示「保留 / 重复」计数，重复的「王思远」标黄并被删除。

**字幕**：`缺失值：先标红定位，再用均值滚入填充`
`重复行：逐行计算指纹，重复的标黄后删除`

**讲解词**：
> 接着做清洗。加入「缺失值处理」，点播放键单步执行：它会先扫描作用列，把空值一个个标红定位，
> 然后算出均值，让数值滚动着填进这些空位，你能清楚看到哪一格被填了什么。
> 再去做重：它给每一行算一个"指纹"，指纹重复的行会被标黄，最后把重复的「王思远」删掉。

## 镜头 4｜派生指标与排序：FLIP 平滑重排（0:44 – 0:55）

**操作**：加入「新增计算列」（总分 = 语文 + 数学 + 英语）→ ▶；加入「排序」（总分降序）→ ▶。

**画面重点**：新列从右侧滑入，数字逐个滚动生成；排序时先读取排序键，再整表平滑滑动重排。

**字幕**：`新增计算列从右侧滑入 · 排序是整表平滑重排`

**讲解词**：
> 接下来造一个派生指标：总分 = 语文 + 数学 + 英语。新列会从表格右侧滑入，然后逐行把结果算出来。
> 再按总分降序排序。这里用的是 FLIP 动画：先记录每一行的旧位置，移动之后再反向位移过渡回去，
> 所以看起来是整张表**平滑滑动**重排，而不是瞬间闪一下。

## 镜头 5｜分组聚合 + 图表联动（0:55 – 1:28）

**操作**：加入「分组聚合」（按 班级，求 语文 均值）→ ▶；切换图表到「条形图」。

**画面重点**：同班行染同色 → 整表按组重排聚拢 → 每组被"吸"成一行，解说逐组报出
「组「一班」：8 行 → 均值 84.4」；右侧图表自动联动为「按班级的汇总柱状图」（纵轴：总分均值）。

**字幕**：`分组聚合：同组上色 → 聚拢 → 坍缩成汇总行`
`同组上色后聚拢在一起，然后逐组坍缩成一行汇总`
`图表自动联动：切换到「按班级的汇总柱状图」`

**讲解词**：
> 分组聚合是最容易忽略过程的一步。这里先按班级给每一行上色，让同组的行聚到一起，
> 然后一组一组坍缩：组内多行飞到组首行的位置并消失，解说同步报出这一组的行数和均值。
> 三个班级最终变成三行汇总；右边的图表也自动联动成了按班级的柱状图，纵轴就是刚算出来的「总分均值」。
