使用说明

  1. 选数据：左上角切换内置数据集，或「导入数据 / 粘贴数据」载入自己的文件。
  2. 搭流水线：在左侧「操作库」点击操作，加入中间流水线；在步骤卡片里设置参数。
  3. 看过程：点击「运行全部」，表格会以动画演示扫描 → 比较 → 标记 → 删除 → 结果的完整逻辑。
  4. 控节奏：底部播放条可播放 / 暂停 / 单步 / 跳转，速度 0.5×–4×，也可勾选「只看结果」。
  5. 读结果：右侧同步更新数据概览、分布图、描述统计与等价 pandas 代码。

快捷键：空格 播放/暂停 · ← 上一步 · → 下一步 · R 运行全部
